# ADR-002: React as Frontend Framework

**Status:** Accepted  
**Date:** 2025-10-31  
**Decision Makers:** Dennis Byberg

## Context and Problem Statement

The project needs a JavaScript framework to build an interactive web application for the booking platform.

## Decision Drivers

- Already familiar with React from education
- Industry standard with most job opportunities
- Used at internship placement (ESS Group)
- Large ecosystem and community support

## Considered Alternatives

No alternatives were seriously considered. React was the natural choice given education background and internship alignment.

## Decision

We will use **React** as the frontend framework.

**Rationale:**

- **Education alignment**: Already learned React during frontend specialization
- **Career preparation**: Used at ESS Group (internship placement)
- **Industry standard**: Most widely used frontend library
- **Large ecosystem**: Many libraries and resources available
- **Component-based**: Good for building reusable UI components

## Consequences

### Positive Consequences

- Can apply knowledge from education directly
- Prepares for internship at ESS Group
- Easy to find help and tutorials
- Large selection of component libraries

### Negative Consequences

- Need to learn additional libraries (routing, state management)
- JSX syntax takes some getting used to
