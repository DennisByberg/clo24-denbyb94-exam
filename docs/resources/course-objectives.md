# 🎯 Course Objectives

## Overview

This document outlines the key learning objectives and expectations for the cloud development course project.

## Course Goals

### 1. Problem Definition & Scope

Choose and define a problem that is relevant to cloud development.

### 2. Project Management

Plan, execute, and follow up on an independent project over eight weeks.

### 3. Self-Directed Learning

Learn new technology/methodology independently, document the process, and demonstrate results.

### 4. Technical Documentation & Presentation

Deliver a technical report (Swedish + English abstract) and a professional presentation.

### 5. Peer Review & Reflection

Provide opposition on a classmate's work and reflect on your own learning journey.

### 6. Ownership & Accountability

Supervision is available as support – but you own the plan, deliverables, and quality work.

---

_This course emphasizes independent learning, professional project management, and technical communication skills essential for cloud development careers._
